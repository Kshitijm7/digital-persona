# Credits & Acknowledgments

Building a real-time, emotionally responsive AI agent is an incredibly complex endeavor that relies on the hard work of countless developers, open-source maintainers, and visionary companies. Digital Persona stands on the shoulders of giants.

We humbly and respectfully acknowledge the following projects, tools, and platforms that made this vision possible:

## 🌐 Google Cloud & AI Infrastructure

- **[Gemini 2.5 Flash Live API](https://deepmind.google/technologies/gemini/):** The brilliant, fast, and native multimodal brain that powers every thought, word, and tool-call of our avatar.
- **[Google Cloud Run](https://cloud.google.com/run):** The robust, scalable cloud environment ensuring our backend is always securely available.
- **[Vertex AI](https://cloud.google.com/vertex-ai):** For powerful enterprise AI grounding and foundation model deployment capabilities.
- **[Google GenAI SDK](https://github.com/google/genai-js):** The crucial library enabling our low-latency WebSocket connections.

## 🛠️ Open Source Ecosystem

This project relies on a vibrant ecosystem of open-source frameworks:

- **[React](https://react.dev/):** The core UI library powering the frontend architecture.
- **[Next.js](https://nextjs.org/):** The React framework that provided our full-stack capabilities and seamless deployment targets.
- **[React Three Fiber (R3F)](https://docs.pmnd.rs/react-three-fiber):** The remarkable declarative 3D engine that brings the avatar to life within the browser.
- **[VitePress](https://vitepress.dev/):** The incredibly fast static site generator that powers this very documentation site.
- **[Mermaid.js](https://mermaid.js.org/):** For rendering our complex architectural diagrams gracefully.

## 🎨 3D Avatar Generation

- **[Ready Player Me](https://readyplayer.me/):** The phenomenal cross-game avatar platform that generated the 3D model, complete with ARKit blendshapes essential for emotive facial animations and accurate lip-syncing.

## 🪄 AI Development Assistants

- **[Antigravity IDE](https://gemini.google.com/):** This project was brought to life ("vibe coded") in collaboration with Antigravity—an incredibly powerful AI agentic coding assistant that helped write, debug, and orchestrate the codebase.
